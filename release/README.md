# Download packages

- **Guitar-Composer-Studio.zip**: extract, open `index.html`. No installation,
  ChatGPT account, Ollama or terminal is required. Local music recommendations
  are based on rules; external generative AI is optional.
- **Guitar-Composer-Studio-Web.zip**: deploy the extracted contents to static
  HTTPS hosting for laptop/iPhone access. It includes the standalone ZIP download.

Build with `npm run build:release`. GitHub Pages owner instructions are in
[PORTFOLIO_DEPLOY.md](../docs/PORTFOLIO_DEPLOY.md). Availability of a public address
requires the host to be enabled; the ZIPs themselves are ready to use.
